# Evidence to add here

Add screenshots only after capturing them from your own real test run. Suggested filenames:

1. `01_home_page.png` — application home page open in browser.
2. `02_search_venom.png` — search field/result for Venom.
3. `03_search_no_results.png` — no-results state for an unavailable title.
4. `04_duplicate_email_validation.png` — duplicate-email registration feedback.
5. `05_weak_password_result.png` — actual result for the weak-password check.
6. `06_logged_out_booking_history.png` — actual response/redirect for signed-out booking history.
7. `07_robot_report.png` — Robot Framework `report.html` showing actual test summary.
8. `08_robot_log_failure_detail.png` — log page for a real failed test, if present.
9. `09_locust_statistics.png` — Locust statistics after an actual run.
10. `10_locust_report.png` — generated Locust HTML report.
11. `11_bandit_output.png` — Bandit output after an actual scan.

For each screenshot:
- Capture the actual browser, terminal or report window.
- Keep the URL/test ID and relevant output visible where appropriate.
- Hide personal information and credentials.
- Use filenames matching the test ID.
- Add a short caption in a README or report.
- Never edit a screenshot to change a test result. Cropping for readability is fine.
- Do not upload generated mockups as if they were real execution evidence.
